# ConnectX shop settings (current revision)

Each shop manages its own ConnectX Email sender/reply-to, on/off switch and license-capped daily quota in **ConnectX → Email → Settings**. SMS is independent: **ConnectX → SMS Gateway → Settings** contains the shop's SMS enable/disable switch, automatic triggers and SMS message templates. Staff need the appropriate shop permissions. The Owner keeps central service credentials, and plan/add-on entitlements still govern access.

The **Attachment HTML templates** editor and backend custom document wrappers were removed in this revision. Shops can still attach the existing real invoice, receipt, reminder, return, exchange and refund details within emails from the Email composer; those documents are generated by EMS from current shop records and are not customizable HTML templates. Old saved wrapper markup is ignored. SMS message templates are a separate feature and were retained.

For existing PostgreSQL, apply `supabase/migrations/064_connectx_shop_email_settings.sql` if outstanding; for existing D1, apply `supabase/d1/migration_connectx_shop_email_settings.sql` if outstanding. Fresh complete baselines include the email table. Until migration 064 is applied, current email/SMS delivery remains available but Email Settings are read-only; a save returns a migration-required error. Global owner limits and Brevo verification still apply. For the complete App Store/ConnectX changes and migration 065, see `APP_STORE_CONNECTX_REVISION.md`.
